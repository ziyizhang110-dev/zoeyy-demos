# 守夜人 · 生存清单

A gamified daily survival checklist / task manager web app.

## How to use

1. Open `index.html` in a browser (or host it as a static site).
2. Add to home screen on mobile for a more app-like experience.
3. Customize goals, reminder times, and character art in the **营地 (Camp)** tab.

## Features

- Daily plan → work → evening review loop
- Priority levels (important items can trigger "monster" encounters if unfinished)
- Character companions with voice/SFX (Web Audio)
- Streak tracking and 30-day calendar
- Fully local (data stays in browser localStorage)
- Custom character image upload
